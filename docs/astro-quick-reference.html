Capture

/astro statusState, camera, active profile
/astro captureOne frame at profile settings
/astro capture frames=N exposure=S iso=NCapture with overrides
/astro preview exposure=S iso=NQuick single frame
/astro lastResend last preview
/astro abortStop current session
Abort waits. It stops between frames — a 300 s exposure already running will finish first.

Timelapse

/astro timelapse profile=<name>Run a named profile
/astro timelapse profile=<name> duration=SProfile, any value overridden
/astro timelapse interval=S frames=NManual, by frame count
/astro timelapse interval=S duration=SManual, by total time

Before a session

1. Camera on, dial to M (Manual).
2. Menu → Setup → USB Connection → PC Remote.
If it shows as “charging mode”, gphoto2 cannot see it.
3. /astro battery to confirm the link.

Rules of thumb

500 rule. Max exposure before star trails ≈ 500 ÷ focal length. A 20 mm lens → ~25 s.
Names matter. A profile called timelapse-* runs a sequence; any other name is a single shot. Presets are camera settings only.
Bulb is automatic. Over 30 s switches to bulb with no action needed.
Mount control is not implemented — /astro track replies “Mount not connected yet”.
